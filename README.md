# MediFlow CRM — منصة إدارة العيادات الطبية وحجوزات الواتساب

نظام متكامل وشامل لإدارة العيادات والمراكز الطبية مع ربط رسمي بمنصة WhatsApp Business Platform Cloud API ومساعد ذكي للرد الآلي وحجز المواعيد.

---

## المميزات الرئيسية
- 🩺 **سجل المرضى الكامل:** إدارة المرضى، البحث الفوري بالاسم أو الهاتف، ومنع التكرار وحفظ موافقة الواتساب.
- 📅 **جدول المواعيد والتقويم:** فحص وتفادي التعارض الزمني التلقائي، وإدارة حالات الحجز والإلغاء وإعادة الجدولة.
- 💳 **المالية والمدفوعات:** تسجيل الدفعات النقدية والمصرفية، حساب المبالغ المتبقية، وتصدير التقارير إلى CSV.
- 💬 **ربط واتساب الرسمي (Meta Cloud API):** استقبال الرسائل والتحقق من التوقيع والـ Webhook، مع محاكي تفاعلي للتطوير (Mock Provider).
- 🤖 **المساعد الذكي للواتساب:** يفهم الرسائل بالعربية واللهجة العراقية ("أريد أحجز موعد باچر"، "شنو الخدمات"، "الأسعار") ويقوم بإنشاء الحجز الفعلي في قاعدة البيانات.
- ⏰ **التذكيرات الآلية:** جدولة التذكيرات قبل 24 ساعة وساعتين عبر نقطة فحص دورية (Cron).
- 🌐 **ثنائي اللغة (Bilingual):** تصميم احترافي باللغة العربية (RTL) مع إمكانية التبديل إلى الإنجليزية (LTR).
- 🔒 **الأمان والصلاحيات (RBAC & RLS):** عزل البيانات وسياسات Row Level Security في PostgreSQL وأربعة أدوار مستخدمين (مالك، مدير، طبيب، موظف استقبال).

---

## متطلبات التشغيل
- Node.js >= 18.0.0 (تم الاختبار على Node.js v24.21.0)
- npm >= 9.0.0
- مشروع Supabase (PostgreSQL + Auth) اختياري للإنتاج أو العمل بالنمط المحلي

---

## التشغيل المحلي (Getting Started)

1. **تثبيت الحزم:**
```bash
npm install
```

2. **إعداد المتغيرات البيئية:**
قم بنسخ ملف `.env.example` إلى `.env.local`:
```bash
cp .env.example .env.local
```

3. **تشغيل خادم التطوير:**
```bash
npm run dev
```
افتح المتصفح على [http://localhost:3000](http://localhost:3000).

4. **تشغيل الفحص وبناء الإنتاج:**
```bash
npm run build
```
