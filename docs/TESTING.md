# MediFlow CRM — دليل الاختبارات وضمان الجودة (Testing Guide)

## 1. استراتيجية الاختبارات
يغطي إطار الاختبارات الوحدات والوظائف الحيوية التالية:
1. **التحقق من صحة المدخلات:** منع إضافة مريض بدون اسم أو هاتف، والتحقق من صحة الصيغ.
2. **منع التعارض الزمني في المواعيد:** التأكد من رفض حجز موعد جديد في حال وجود موعد سابق متقاطع في نفس التوقيت.
3. **العمليات المالية:** احتساب المبالغ المجمعة وطرق الدفع.
4. **محاكي ورسائل الواتساب:** فحص استجابة الويب هوك وتحديد النوايا (Intent Recognition) وإنشاء المواعيد آلياً.
5. **جدولة التذكيرات:** فحص طابور التذكيرات للمواعيد خلال 24 ساعة ومنع الإرسال المكرر.

## 2. أوامر التشغيل
```bash
# تشغيل فحص الأنماط البرمجية (Lint)
npm run lint

# تشغيل البناء الكامل للإنتاج
npm run build
```
