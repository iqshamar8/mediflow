# MediFlow CRM — سياسة الأمان وحماية البيانات (Security Policy)

## 1. عزل البيانات وصلاحيات الوصول (Row Level Security)
- تم تفعيل سياسات Row Level Security (RLS) على كافة الجداول التي تحتوي على بيانات المرضى أو العمليات المالية أو المحادثات.
- يتم التحقق من عضوية المستخدم في العيادة باستخدام الدالة:
  `current_user_has_clinic_access(clinic_id)`
- تم تحديد 4 أدوار أساسية:
  1. `owner`: المالك، صلاحية كاملة على إعدادات العيادة، الخدمات، التقارير المالية وسجلات التتبع.
  2. `admin`: مدير النظام، إدارة الموظفين، المرضى، المواعيد، والمدفوعات.
  3. `doctor`: الطبيب، الوصول لجدول المواعيد الخاص به، سجلات المرضى، وإدخال/تعديل الملاحظات السريرية والتشخيص.
  4. `receptionist`: موظف الاستقبال، تسجيل المرضى، حجز وتعديل المواعيد، وتسجيل الدفعات النقدية دون الوصول للملاحظات السريرية الخاصة.

## 2. إدارة المفاتيح السرية
- لا يتم إرسال `SUPABASE_SERVICE_ROLE_KEY` أو `WHATSAPP_APP_SECRET` إلى المتصفح نهائياً.
- تخضع نقاط النهاية الخارجية (Webhooks) للتحقق من التوقيع الرقمي لمنع انتحال الهوية.
- نقطة نهاية الجدولة والتذكيرات `/api/cron/reminders` محمية برمز سري `Bearer CRON_SECRET`.
